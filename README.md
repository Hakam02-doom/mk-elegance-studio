# MK Elegance Studio

Website for MK Elegance Studio — threading, waxing, brows & lashes and Diego dalla Palma facials in Uptown Waterloo, Ontario.

- `site/` — the static website (open `site/index.html`, or deploy the folder as-is). Vercel serves this folder.
- `build-tools/` — the scripts used to mirror the Morgana (Shopify) theme and apply the brand (copy, colours, fonts, images).

Built on the Morgana (Shopify) theme layout. The layout comes from a paid theme: hold a licence for it before using this site in production.
